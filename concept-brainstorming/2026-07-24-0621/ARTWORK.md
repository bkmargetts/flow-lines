# Plate VIII — A Machine of Uncertain Purpose

## Artist statement

The Machine generator's own doc comment calls its output "cheerfully
impossible" — gear trains that mesh at true pitch, belts that run on real
common tangents, linkages that are properly pose-solved, welded into
mechanisms that don't drive anything and don't need to. This piece takes
that impossibility and dresses it in the *total authority* of 18th- and
19th-century technical engraving: the encyclopaedia plate and the patent
drawing. A ruled double neatline. A subject header. Section cutaways that
bite into the big wheels and reveal cross-hatched interior tone. Dashed
hidden lines where one part passes behind another. A numbered general
view (Fig. 1) and a second, enlarged inset (Fig. 2) showing one gear's
cutaway in close-up — the exact device Diderot's *Encyclopédie* plates
use to zoom into a mechanism's working parts. A plate title and number,
set in engraved capitals, sit in their own ruled compartment at the foot
of the sheet.

None of that apparatus is decoration bolted onto a random render. It's
the connective tissue real technical illustration uses to make a claim:
*this is real, this works, here is the proof in section.* Pointed at a
machine that is provably decorative — generated by a `synth.ts` that
grows a part graph with no function, no material, no client — the
apparatus becomes the whole joke, and also not entirely a joke. Every
draftsman who ever inked one of these plates was, in some sense, drawing
a fiction of total mechanical clarity over something more contingent
than the ruled lines let on. This plate just admits it up front: the
machine's purpose is *uncertain* by name, and the drawing insists on its
credentials anyway.

Of the machine seeds explored, seed 3 survived because it reads as one
composed gear train rather than a field of parts: a five-wheel cascade
falls from the packed upper-left corner down through a crossed pair of
rope/belt drives to a small counterweight at lower right, with two
section cutaways breaking up the tone. Other seeds (8, 14, and the
earlier default-canvas scouting round) were competent but either left an
un-anchored gap in one corner or scattered the linkage rods without a
throughline for the eye to follow. The Fig. 2 inset is a second,
independent render — tuned down to near-zero frame density and a single
enlarged gear so it reads as a close-up rather than a smaller copy of
Fig. 1 — deliberately not a crop of the main figure, the way a real
plate's detail view is drawn at its own scale, not photographically
reduced.

## Materials

- **Paper**: G. F Smith Colorplan, 135 gsm, colour *Ivory* — A3
  (297×420 mm), the plotter's maximum single sheet. Colorplan's smooth,
  faintly coated finish takes a fine technical line cleanly (no toothy
  paper-texture breaking up the hairline hatch) while still reading as a
  warm, pre-white "aged" stock rather than bright printer paper.
- **Ink**: Sakura Pigma Micron 03 (0.35 mm nib), colour *Sepia* — a
  single pigmented, waterproof fineliner, one pen at one width for the
  entire plate (neatline, machine linework, and captions all plot in the
  same pass with the same pen — no swap, no second colour).
- Nothing else: no wash, no mounting tape in the piece itself (framing
  suggestion below is presentation, not part of the plotted object).

## Process

1. Build the repo (`pnpm install && pnpm build`) and generate
   `artwork.svg` with the reproduction command below.
2. Load the AxiDraw (or compatible XY pen plotter) with the Sakura Pigma
   Micron 03 Sepia pen, 0.3 mm effective line width.
3. Tape the A3 Colorplan Ivory sheet to the bed, portrait orientation,
   registered to the plotter's home corner.
4. Plot `artwork.svg` in a single pass — one file, one pen, no layer
   swaps. The SVG is tagged at true A3 physical size (297×420 mm), so no
   scaling step is needed.
5. Let the ink cure ~5 minutes (Pigma pigment ink sets fast, but the
   dense cross-hatch in the two cutaway wedges and the Fig. 2 inset lays
   down a lot of ink in a small area) before lifting the sheet from the
   bed.
6. *Optional, hands-on:* a single, very light pass of a barely-damp
   cotton pad along the outer 5–8 mm of all four edges only — clear
   water, not a wash — to soften the cut edge of the Colorplan just
   enough to suggest a page pulled from a bound folio, without touching
   the ruled interior. Test on an offcut first; skip entirely for a
   crisper, unaged result — the plate reads well either way.
7. Mount: float-mount in a deep frame (the neatline should have a few mm
   of breathing room from the mat window, not be trimmed to it) with a
   wide warm-white mat and a dark walnut or black frame moulding — the
   plate is doing 18th-century-engraving cosplay; a heavy gilt frame
   oversells it, a plain dark one lets the ivory paper and sepia line do
   the work.

## Plot settings

- Paper: A3, portrait, 297×420 mm (the SVG's native size — plot at 100%,
  no fit-to-page scaling).
- Margin: baked into the composition (14 mm outer neatline, a second
  rule 3 mm further in) — no additional plotter margin needed.
- Pen: single pen, 0.3 mm.
- ~1,700 plotted strokes after `optimizePlot` endpoint-chaining and
  nearest-neighbour ordering.

## Reproduction

Deterministic from two seeds: `3` for the general-arrangement figure,
`501` for the enlarged cutaway inset. Build the repo, save the script
below as `plate.mjs` **in the repo root** (it imports `packages/core/dist`
by relative path), then run:

```sh
pnpm install && pnpm build
node plate.mjs concept-brainstorming/2026-07-24-0621/artwork.svg 3 501
node scripts/svg-to-png.mjs concept-brainstorming/2026-07-24-0621/artwork.svg \
  concept-brainstorming/2026-07-24-0621/preview.png \
  --width 1600 --background '#f4ecd8' --stroke '#2d1c10'
```

`plate.mjs`:

```js
// Plate VIII — "A Machine of Uncertain Purpose"
//
// Composites an engraved-plate layout on top of the core Machine generator:
// a main figure, a small enlarged cutaway-detail inset, a double-ruled
// neatline, and engraved stroke-font captions. Config-only — this assembles
// core's own exported primitives (generateMachine, pageBorder, optimizePlot,
// toSVG, plus the stroke font used internally by the Planet generator's
// plate furniture); no repo source was changed.
//
// Run from the repo root after `pnpm build`:
//   node plate.mjs artwork.svg 3 501
import { writeFileSync } from 'node:fs';
import { resolve } from 'node:path';

const { generateMachine, toSVG, optimizePlot, pageBorder } = await import(
  './packages/core/dist/index.js'
);
// stroke-font isn't barrel-exported (plate captions are a generator-specific
// concern, used internally by the Planet generator's plate furniture) — reach
// the built module directly for this scratch composition.
const { textToStrokes, textWidth } = await import(
  './packages/core/dist/stroke-font.js'
);

const PXPERMM = 3; // matches BASE_PX_PER_MM
const mm = (v) => v * PXPERMM;

const PAGE_W_MM = 297; // A3 portrait — the plotter's maximum single sheet
const PAGE_H_MM = 420;

const OUTPUT = process.argv[2] ?? 'plate.svg';
const MAIN_SEED = Number(process.argv[3] ?? 3);
const INSET_SEED = Number(process.argv[4] ?? 501);

// ---- layout (mm) ---------------------------------------------------------
const outerMargin = 14;
const innerInset = 3; // second rule 3mm further in — the classic double neatline
const ix0 = outerMargin + innerInset;
const ix1 = PAGE_W_MM - outerMargin - innerInset;
const iy0 = outerMargin + innerInset;

const headerY = iy0 + 2;
const rule1Y = iy0 + 12;
const mainY0 = rule1Y + 4;
const mainY1 = 296;
const fig1LabelY = mainY1 + 3;
const subRowY0 = fig1LabelY + 9;
const subRowY1 = subRowY0 + 64;
const fig2LabelY = subRowY1 + 2;
const rule2Y = fig2LabelY + 8;
const titleY = rule2Y + 4;
const plateNumY = titleY + 10;

const lines = [];

function translate(srcLines, dx, dy) {
  for (const l of srcLines) {
    lines.push({ ...l, points: l.points.map((p) => ({ x: p.x + dx, y: p.y + dy })) });
  }
}

function rectLines(x0, y0, x1, y1, layer) {
  lines.push({
    points: [{ x: x0, y: y0 }, { x: x1, y: y0 }, { x: x1, y: y1 }, { x: x0, y: y1 }, { x: x0, y: y0 }],
    layer,
  });
}

function centeredText(text, cyPx, sizeMm, layer = 'label') {
  const w = textWidth(text, mm(sizeMm));
  const x = mm(PAGE_W_MM / 2) - w / 2;
  const y = cyPx - mm(sizeMm) / 2;
  for (const stroke of textToStrokes(text, x, y, mm(sizeMm))) lines.push({ points: stroke, layer });
}

function centeredTextAt(cxMm, cyMm, text, sizeMm = 3.0, layer = 'label') {
  const w = textWidth(text, mm(sizeMm));
  const x = mm(cxMm) - w / 2;
  const y = mm(cyMm) - mm(sizeMm) / 2;
  for (const stroke of textToStrokes(text, x, y, mm(sizeMm))) lines.push({ points: stroke, layer });
}

function leftText(text, x0Mm, cyPx, sizeMm, layer = 'label') {
  const y = cyPx - mm(sizeMm) / 2;
  for (const stroke of textToStrokes(text, mm(x0Mm), y, mm(sizeMm))) lines.push({ points: stroke, layer });
}

// ---- neatline (double rule) ----------------------------------------------
lines.push(...pageBorder({ width: mm(PAGE_W_MM), height: mm(PAGE_H_MM), marginPx: mm(outerMargin), layer: 'border' }));
lines.push(...pageBorder({ width: mm(PAGE_W_MM), height: mm(PAGE_H_MM), marginPx: mm(outerMargin + innerInset), layer: 'border' }));

// ---- header + rule --------------------------------------------------------
centeredText('MECHANICAL ARTS: SERIES II', mm(headerY + 2), 3.2);
lines.push({ points: [{ x: mm(ix0), y: mm(rule1Y) }, { x: mm(ix1), y: mm(rule1Y) }], layer: 'border' });

// ---- Fig. 1 — general arrangement -----------------------------------------
const mainWmm = ix1 - ix0;
const mainHmm = mainY1 - mainY0;
const a4AreaMm2 = 210 * 297;
const main = generateMachine({
  width: mm(mainWmm),
  height: mm(mainHmm),
  margin: mm(8),
  seed: MAIN_SEED,
  complexity: 0.87,
  connectivity: 0.88,
  cutaways: 3,
  mechanisms: 0.85,
  frameDensity: 0.7,
  shading: 0.62,
  gearSize: 95,
  scaleVariety: 0.6,
  hatchSpacing: 3.0,
  sheetFactor: Math.max(1, (mainWmm * mainHmm) / a4AreaMm2),
  hiddenLines: true,
  wobble: 0.8,
  sketch: 0.22,
});
translate(main.lines, mm(ix0), mm(mainY0));
leftText('FIG. 1. — GENERAL ARRANGEMENT.', ix0, mm(fig1LabelY + 2), 3.4);

// ---- Fig. 2 — enlarged cutaway detail --------------------------------------
const insetWmm = 104;
const insetHmm = subRowY1 - subRowY0;
const insetX0mm = ix1 - insetWmm;
const inset = generateMachine({
  width: mm(insetWmm),
  height: mm(insetHmm),
  margin: mm(4),
  seed: INSET_SEED,
  complexity: 0.3,
  connectivity: 1,
  cutaways: 2,
  mechanisms: 0.1,
  frameDensity: 0,
  shading: 0.85,
  gearSize: 190,
  scaleVariety: 0.1,
  hatchSpacing: 1.8,
  sheetFactor: 1,
  hiddenLines: true,
  wobble: 0.4,
  sketch: 0.12,
});
translate(inset.lines, mm(insetX0mm), mm(subRowY0));
rectLines(mm(insetX0mm), mm(subRowY0), mm(insetX0mm + insetWmm), mm(subRowY1), 'border');
centeredTextAt(insetX0mm + insetWmm / 2, fig2LabelY + 2, 'FIG. 2. — DETAIL OF A GEAR CUTAWAY, ENLARGED.');

// ---- caption block ----------------------------------------------------------
lines.push({ points: [{ x: mm(ix0), y: mm(rule2Y) }, { x: mm(ix1), y: mm(rule2Y) }], layer: 'border' });
centeredText('A MACHINE OF UNCERTAIN PURPOSE', mm(titleY + 3.5), 6.5);
centeredText('PLATE VIII.', mm(plateNumY + 2), 3.6);

// ---- assemble + optimize -----------------------------------------------------
let result = { lines, width: mm(PAGE_W_MM), height: mm(PAGE_H_MM), seed: MAIN_SEED };
result = optimizePlot(result, {});

writeFileSync(
  resolve(OUTPUT),
  toSVG(result, {
    strokeColor: '#2d1c10',
    strokeWidth: 0.9,
    physicalWidth: `${PAGE_W_MM}mm`,
    physicalHeight: `${PAGE_H_MM}mm`,
  })
);
console.log(`wrote ${OUTPUT} (${result.lines.length} lines)`);
```

`preview.png` was rendered from `artwork.svg` with
`scripts/svg-to-png.mjs`, recolouring background/stroke to approximate
the Colorplan Ivory paper and Pigma Micron Sepia ink
(`--background '#f4ecd8' --stroke '#2d1c10'`); the plotted piece itself
is a single-ink line drawing with no colour information beyond the one
pen.

## Wishes

- `generateMachine` has no notion of a "detail" render that shares
  geometry with a parent figure — Fig. 2 here is an independently seeded
  machine tuned to resemble a close-up, not an actual zoom into a part of
  Fig. 1. A future `detailOf(machineResult, partId)` that re-renders one
  real gear from the main synth at a larger scale (same tooth count,
  same phase) would let a plate's inset be *literally* the part it claims
  to be, which the genre's authority depends on and this piece only
  approximates.
- The stroke font (`stroke-font.ts`) is a genuinely reusable "plate
  furniture" primitive — currently reachable only as an unexported deep
  import shared ad hoc between Planet's furniture and this script. It
  would be worth promoting `textToStrokes`/`textWidth` (and maybe a small
  `plateCaption()` helper bundling a title/number/rule the way this
  script hand-rolls one) to the core barrel so future sessions don't
  reach past it.
